# مجمع أم القرى الطبي - بركاء، سلطنة عمان
## نظام إدارة العلاج الطبيعي والتأهيل الطبي الشامل 2026 (23 موديولاً متكاملاً)

### 1. مميزات النظام المنجزة بالكامل:
- **المرحلة الأولى: الأنظمة الأساسية (1-10)**
  1. نظام الجدولة خماسي الأبعاد لمنع تعارض الموارد (Specialist, Bed, Device, Patient Time, Procedure Duration).
  2. ملف تقييم الـ SOAP Notes المطور لجميع الجلسات مع مقياس الألم VAS (0-10) والمدى الحركي ROM.
  3. الخريطة البصرية التفاعلية لمواضع الألم (Visual Interactive Body Map).
  4. الحواسب الطبية الإكلينيكية (DASH, Oswestry ODI, Berg Balance Scale).
  5. نظام الكورسات والباقات (تتبع الرصيد الإكلينيكي والمالي، وخصم 10% للباقات 5+ جلسات).
  6. مكتبة فيديوهات التمارين المنزلية المحتشمة المتوافقة مع الخصوصية العمانية.
  7. لوحة تقارير الرسم البياني التلقائي (ROM & Pain Progress Line Chart).
  8. نظام الفوترة والربط مع شركات التأمين الصحي العمانية (ضمان، ميدنت، نيكست كير).
  9. إشعارات واتساب الذكية للأطباء والمراجعين (WhatsApp Business Cloud API).
  10. تقرير التخرج الطبي النهائي التلقائي بصيغة PDF مع الختم والاعتماد.

- **المرحلة الثانية: إضافات الذكاء الاصطناعي 2026 (11-15)**
  11. مساعد التوثيق الصوتي الذكي (AI Physiotherapy Scribe).
  12. التحليل الحركي البصري بالكاميرا بدون علامات (Markerless AI ROM Goniometer).
  13. مدرب التمارين المنزلي الذكي بالكاميرا (AI Rep Counting & Voice Safety Feedback).
  14. المساعد الصوتي العماني الذكي لإدارة قائمة الانتظار وإعادة توزيع الشواغر.
  15. نظام التنبؤ الذكي بالتعافي (Predictive Outcome Analytics).

- **المرحلة الثالثة: العيادات التخصصية (16-23)**
  16. عيادة العمود الفقري: خريطة الفقرات الرادارية وبروتوكولات شد الفقرات بالكمبيوتر.
  17. عيادة الركبة والخشونة: حاسبة الحمل المفصلي ونظام الأمان لجهاز BTL 4000.
  18. عيادة الكتف والطرف العلوي: متتبع زوايا الكتف ومؤشر الكتف المتجمد.
  19. عيادة الإصابات الرياضية: حارس ومؤشر الجاهزية للعودة للملاعب (RTP Checklist Gatekeeper).
  20. عيادة التأهيل بعد الجراحة: نظام الخطوط الحمراء الجراحية ومتابعة التئام الجروح.
  21. عيادة كبار السن: مقياس مخاطر السقوط والواجهة الميسرة ذات الأزرار والصوت التوجيهي (Elderly UI).
  22. عيادة التأهيل العصبي: متتبع التشنج العضلي بمقياس أشفورث (Modified Ashworth Scale).
  23. عيادة اللياقة الطبية وتخفيف الوزن: ربط قراءات InBody وحاسبة السعرات الحركية METs.

### 2. طريقة التثبيت كأيقونة تطبيق على الموبايل (PWA - Android & iPhone):
- **على أجهزة Android (Chrome / Samsung Internet):**
  1. افتح رابط التطبيق.
  2. اضغط على زر **"تثبيت التطبيق"** الأخضر الظاهر في أعلى الشاشة، أو اضغط على قائمة المتصفح (الثلاث نقاط) واختر **"تثبيت التطبيق" (Install App / Add to Home Screen)**.
  3. سيظهر التطبيق كأيقونة مستقلة على شاشة هاتفك مثل تطبيقات متجر Google Play تماماً، ويعمل بدون شريط المتصفح وبدعم غير متصل بالإنترنت.
- **على أجهزة iPhone / iPad (Safari):**
  1. افتح الرابط في متصفح Safari.
  2. اضغط على أيقونة **المشاركة (Share)** أسفل الشاشة.
  3. مرر لأسفل واختر **"إضافة إلى الصفحة الرئيسية" (Add to Home Screen)**.
  4. سيتم تثبيت أيقونة مجمع أم القرى بشعارها الرسمي على شاشة الآيفون.

### 4. النشر التلقائي عبر Vercel أو Coolify:
- **النشر على Vercel:**
  1. قم بتسجيل الدخول إلى Vercel.
  2. اختر **"Add New Project"** واستورد مستودع GitHub الخاص بك.
  3. اختر إعدادات البناء الافتراضية (`npm run build`).
  4. سيتم نشر الموقع فوراً مع رابط دائم وشهادة SSL مجانية.
- **النشر على خادمك الخاص عبر Docker أو Coolify:**
  - تم تجهيز ملف `docker-compose.yml` وملف `Dockerfile` داخل المشروع:
  ```bash
  docker-compose up -d --build
  ```

### 5. إعداد قاعدة بيانات Supabase (PostgreSQL):
- افتح حسابك في [Supabase](https://supabase.com).
- افتح قسم **SQL Editor**.
- افتح ملف `supabase_schema.sql` المرفق في هذا المشروع وانسخ محتواه واضغط **Run**.
- ستقوم السكربت بإنشاء كافة الجداول والعلاقات وقواعد الأمان (RLS) تلقائياً.
